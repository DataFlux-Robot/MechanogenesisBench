# 范围与声明边界

[English](SCOPE.md) | **简体中文**

## 公开对象

MechanogenesisBench 通过版本化任务包、公开输入视图、内容寻址提交、评测方持有的隐藏信息
和 fail-closed 评分来评测第三方系统。它不规定参与者使用何种模型、规划器、优化器或训练方法。

长期目标对象是一个能够把物理目标转化为机构研究规格（MRS）、构造程序、实验和可审计证据的
智能体。有界递归赛道还要求判断：某一代的物理结果是否在资源匹配、谱系精确的条件下改善后续代。

## 仓库排除边界

公开仓库不包含：

- FLUXPRSI 模型和 researcher 实现；
- 候选更新生成与全参数训练代码；
- 私有训练课程、buffer 和优化器策略；
- 模型 checkpoint、内部 prompt 和实验 artifacts；
- 内部证明开发计划与运维交接；
- 产品运行时和客户数据。

benchmark 中出现 PRSI 和 recursive，是因为它们是 benchmark 计划测量的性质；这不表示
仓库包含 FLUXPRSI 系统，也不表示这些性质已经实现。

## 证据纪律

任何正向结果都必须声明证据等级。一致性 episode 只说明协议可以执行并能正确拒绝；仿真结果
仍受模型限定；硬件声明需要计量、校准、保管链和物理执行 receipts。任何有限 `PRSI-n`
结果都不蕴含无界改进或加速。

Lean 证明的是显式形式模型内部的蕴含，运行时 certificate 将具体字节绑定到这些谓词。
二者都不能替代“模型假设在经验上成立”的证据，也不能替代“训练策略确实能产生可接受后继者”的
可达性结果。
